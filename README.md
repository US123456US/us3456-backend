# US123456US Portfolio

这是一个作品集风格的个人主页模板，适合展示：

- 个人简介
- 技能能力
- 代表作品
- 工作经历
- 联系方式

## 访问方式

启用 GitHub Pages 后，站点会部署到：

https://US123456US.github.io/us3456-backend/

## 主要文件

- `index.html`：页面结构
- `style.css`：作品集样式
- `script.js`：表单交互逻辑

## 修改说明

1. 进入仓库的 Settings → Pages。
2. Source 选择 `Deploy from a branch`。
3. Branch 选择 `main`。
4. Folder 选择 `/ (root)`。
5. 保存并等待部署完成。

## 自定义内容

你可以直接修改以下内容：

- `index.html`：你的介绍、项目、标题和联系方式
- `style.css`：调整颜色主题、布局和视觉风格
- `script.js`：填写表单逻辑
