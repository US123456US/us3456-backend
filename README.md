# US123456US

这是一个基于 GitHub Pages 的个人主页模板，适合展示你的简介、项目与联系方式。

## 目录

- `index.html`：页面结构
- `style.css`：页面样式
- `script.js`：简单交互逻辑

## 访问方式

在 GitHub 仓库中启用 Pages 后，网站通常会发布到：

https://US123456US.github.io/us3456-backend/

## 使用说明

1. 进入仓库的 Settings → Pages。
2. Source 选择：Deploy from a branch。
3. Branch 选择：`main`。
4. Folder 选择：`/ (root)`。
5. 点击 Save，等待几分钟后即可访问网站。

## 修改内容

你可以直接编辑这些文件：

- `index.html`：更新标题、介绍、项目和联系方式
- `style.css`：修改颜色、布局、间距和样式
- `script.js`：调整表单交互逻辑
